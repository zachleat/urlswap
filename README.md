# URLswap

Generate a bookmarklet that cycles the current URL between origin, dev, and testing domains.

https://zachleat.github.io/urlswap/

Successor to [`jmhobbs/domain-swap`](https://github.com/jmhobbs/domain-swap) (I did a little video on it awhile back: [Domain Swap Chrome Extension](https://www.zachleat.com/web/domain-swap/)) because web browser extensions are maintenance dragons!
